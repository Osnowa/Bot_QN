# 🎲 Угадай число — Telegram Bot

Игровой бот для Telegram, где пользователь угадывает случайное число от 1 до 100 за 5 попыток. Проект демонстрирует навыки асинхронного программирования, работы с БД и контейнеризации.

## 🛠 Технологии

- **Python 3.11+**
- **Aiogram 3** — асинхронный фреймворк для Telegram API
- **PostgreSQL** — хранение статистики игроков
- **Redis** — хранение игровых сессий и FSM состояний
- **Asyncpg** — асинхронный драйвер PostgreSQL
- **Docker / Docker Compose** — контейнеризация
- **Pydantic + environs** — управление конфигурацией

## 💪 Что я умею (демонстрируется проектом)

- ✅ Асинхронное программирование (async/await)
- ✅ Проектирование БД и написание SQL-запросов
- ✅ Пул соединений с PostgreSQL
- ✅ Работа с Redis как с хранилищем сессий
- ✅ Finite State Machine (FSM) для управления игрой
- ✅ Docker-оркестрация трех сервисов (PostgreSQL, Redis, pgAdmin)
- ✅ Обработка ошибок и логирование
- ✅ Чистая архитектура с разделением на модули
